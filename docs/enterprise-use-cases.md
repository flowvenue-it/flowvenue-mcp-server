# Enterprise Use Cases

## Conversational CRM

Flowvenue allows AI agents to navigate CRM workflows conversationally.

Example:

```txt
Show all open opportunities for ACME Corp and create a follow-up task for the sales team.
```

Capabilities involved:
- runtime context navigation
- operational orchestration
- conversational execution

# Process Design Through Conversation

Flowvenue supports conversational process design.

Example:

```txt
Create a customer onboarding process with approval, document collection, and welcome email steps.
```

The MCP runtime can:
- create draft processes
- create steps
- add actions
- validate configurations
- publish operational workflows
