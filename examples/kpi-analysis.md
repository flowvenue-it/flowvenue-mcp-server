# KPI Analysis Example

## Goal

Use Flowvenue MCP to explore operational KPIs conversationally.

---

# Example Prompts

## Sales performance

```txt
Show sales trends for the last quarter grouped by region.
```

---

## Revenue analysis

```txt
Show the top customers by revenue this month.
```

---

## Approval bottlenecks

```txt
Show pending approval requests older than 7 days.
```

---

# Runtime Capabilities

Flowvenue allows AI agents to:
- query operational runtime data
- navigate process instances
- analyze workflow execution
- inspect operational context

---

# MCP Tools Commonly Used

- `list_instances`
- `get_process_runtime_context`
- `connection_context`
- `list_capabilities`

---

# Conversational Runtime

Unlike traditional dashboards, Flowvenue allows operational KPI exploration through natural language conversations.
